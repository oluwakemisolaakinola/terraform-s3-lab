# Terraform S3 Lab

A hands-on AWS cloud engineering mini-project using Terraform to provision and manage an Amazon S3 bucket.

##  Project Overview

This project demonstrates how to use Infrastructure as Code (IaC) with Terraform to create an Amazon S3 bucket on AWS.

Instead of manually creating the bucket through the AWS Console, Terraform defines the infrastructure in code and manages its lifecycle.

##  Technologies Used

- AWS
- Amazon S3
- Terraform
- AWS Provider
- Git
- GitHub
- Linux/Ubuntu

##  Infrastructure Created

- Amazon S3 Bucket
- Region: `eu-west-2` (London)
- Environment: Development
- Project: Cloud Learning
